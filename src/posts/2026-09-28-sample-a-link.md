Sample body text. A post can include an ordinary link, such as <https://www.11ty.dev/>, and the build gives every off-site link `target="_blank"` and `rel="noopener"` so it opens in a new tab.

A link written the usual way, like [the Eleventy docs](https://www.11ty.dev/docs/), gets the same treatment. Links that stay on this site are left alone, since a tapped link to another post should replace the thread the way tapping a row in the list does.
