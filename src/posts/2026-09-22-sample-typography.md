Sample body text. The Markdown library runs with `typographer` on, so text pasted out of a messages app reads like the original rather than like typewriter output.

Straight quotes become curly ones: "like this", and an apostrophe in don't or it's curls the right way round. Two hyphens -- like these -- become an en dash. Three become an em dash --- like these --- which is wider. Three dots turn into a single ellipsis character...

That matters here because a post is usually written somewhere else and pasted in. Nothing in the file marks any of it up; the conversion happens at build time.

Inline code is left alone, so `--flag` and `"string"` survive untouched.
