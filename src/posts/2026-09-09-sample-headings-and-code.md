Sample body text. A longer post can be broken into sections with headings, which render at body size and in semibold rather than as display type -- a heading inside a message bubble should look like a sentence someone emphasised, not like a page title.

## A second-level heading

Text under the heading. Both `h2` and `h3` are styled, and they look the same; the distinction is there for document structure rather than for a visible difference.

### A third-level heading

Inline code uses backticks, so a file like `src/posts/posts.json` or a front-matter key like `summary` can be named in the middle of a sentence without the typographer turning its punctuation into curly quotes.

Fenced blocks work too, though they are narrow at a bubble's width:

```
title: "Short Title"
date: 2026-09-01
```
